## ✨ 핵심 기능

- **🖼️ 선명한 첫 페이지 표지**: PDF 첨부파일의 첫 페이지를 고화질 책 표지 형태로 자동 표시
- **🧠 출판사 안내문 자동 건너뛰기**: JSTOR, Elsevier 등 첫 페이지 안내문(Splash)을 감지해 실제 논문 표지인 **2페이지를 자동 지정**
- **📖 표준 APA 7 저자 인용**: 저자 수에 맞춰 깔끔한 학술 인용 형태(`Kim et al. (2026)`) 자동 표기
- **🚦 신호등 읽기 상태 뱃지**: 원클릭으로 `읽기전 ➔ 읽는중 ➔ 읽음` 순환 변경 (Zotero 태그 `#unread`, `#reading`, `#read`와 실시간 동기화)
- **🔄 원클릭 뷰 전환**: 검색창 바로 옆 `[ ≡ 목록 | ⊞ 바둑판 ]` 버튼으로 언제든 지연 없이 즉시 전환
- **🔍 자유로운 카드 크기 조절**: 상단 슬라이더로 콤팩트한 8열부터 시원한 3열까지 실시간 리사이징
- **⚡ 대용량 서재도 부드러운 스크롤**: 수천 편의 논문이 있어도 끊김 없이 쾌적한 60fps 탐색
- **🌙 다크 모드 & Zotero 설정 완벽 연동**: 눈부심 방지 톤다운 필터 적용, 시스템 글자 크기 및 삭제 정책 100% 반영

## 📦 설치 방법

1. [Releases 페이지](https://github.com/JuKang80/zotero-cover-grid/releases)에서 최신 버전의 `zotero-cover-grid.xpi` 파일을 다운로드합니다.
2. Zotero 상단 메뉴에서 **도구(Tools)** ➔ **플러그인(Plugins)**을 클릭합니다.
3. 플러그인 창 우측 상단의 **톱니바퀴 아이콘(⚙️)**을 누르고 **Install Add-on From File...**을 선택합니다.
4. 다운로드한 `zotero-cover-grid.xpi` 파일을 선택해 설치를 완료합니다.
5. 검색창 오른쪽에 `[ ≡ | ⊞ ]` 버튼이 나타나면 즉시 사용하실 수 있습니다!

## 🎮 마우스 & 키보드 조작법

| 입력 / 단축키 | 동작 및 설명 |
| :--- | :--- |
| **클릭** | 우측 서지정보(메타데이터) 패널 즉시 동기화 |
| **더블클릭 / Enter** | 내장 PDF 리더(또는 시스템 기본 뷰어)로 논문 열기 |
| **방향키 (↑, ↓, ←, →)** | 마우스 없는 카드 탐색 (화면 밖 이동 시 뷰포트 자동 추적 스크롤) |
| **뱃지 클릭** | 읽기 상태 순환 (`읽기전` ➔ `읽는중` ➔ `읽음`) |
| **Cmd/Ctrl + 클릭** | 개별 논문 다중 선택 (토글) |
| **Shift + 클릭** | 연속 범위 다중 선택 |
| **Delete / Backspace** | 선택한 논문 삭제 (컬렉션에서 제외 또는 휴지통 이동) |
| **검색창 입력 / ESC** | 렉 없는 실시간 검색 필터링 (`ESC` 입력 시 즉시 전체 복원) |
