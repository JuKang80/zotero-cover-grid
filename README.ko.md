## ✨ 이런 기능들이 있어요!

- **🖼️ 첫 페이지가 보이는 표지 서가**: PDF 첨부파일의 첫 페이지를 고화질 표지로 자동 렌더링합니다.
- **🧠 똑똑한 출판사 표지 인식**: JSTOR, Elsevier 등 출판사 안내문(Splash Page)이 1페이지에 있는 논문은 진짜 표지인 **2페이지를 자동으로 찾아 표지로 설정**합니다.
- **📖 한눈에 들어오는 APA 7 인용**: 저자 수를 자동으로 인식해 표준 학술 인용 형태(`Kim et al. (2026)`)로 깔끔하게 정리해 보여줍니다.
- **🚦 원클릭 신호등 읽기 뱃지**: 카드의 뱃지를 클릭하면 `읽기전 ➔ 읽는중 ➔ 읽음` 상태가 순환 변경되며, Zotero 공식 태그(`#unread`, `#reading`, `#read`)와 자동 연동됩니다.
- **🔄 클릭 한 번으로 뷰 전환**: 검색창 바로 옆 `[ ≡ 목록 | ⊞ 바둑판 ]` 버튼으로 기존 목록형 뷰와 표지 뷰를 언제든 부드럽게 오갈 수 있습니다.
- **🔍 내 맘대로 카드 크기 조절**: 상단 슬라이더로 책장 크기를 미니멀한 8열부터 큼직한 3열까지 실시간으로 조절할 수 있습니다.
- **⚡ 버벅임 없는 부드러운 스크롤**: 수천 편의 논문이 있어도 화면에 보이는 영역만 스마트하게 처리하여 쾌적하게 탐색할 수 있습니다.
- **🌙 다크 모드 & Zotero 설정 완벽 호환**: 눈부심 방지 다크 모드 톤다운, Zotero 시스템 폰트 크기 및 삭제/휴지통 정책을 그대로 따릅니다.

## 📦 설치 방법 (Install)

1. [Releases 페이지](https://github.com/JuKang80/zotero-cover-grid/releases)에서 최신 버전의 `zotero-cover-grid.xpi` 파일을 다운로드합니다.
2. Zotero 10 상단 메뉴에서 **도구(Tools)** ➔ **플러그인(Plugins)**을 클릭합니다.
3. 플러그인 관리 창 우측 상단의 **톱니바퀴 아이콘(⚙️)**을 누르고 **파일에서 플러그인 설치(Install Add-on From File...)**를 선택합니다.
4. 다운로드한 `zotero-cover-grid.xpi`를 선택하고 설치를 완료합니다.
5. 검색창 오른쪽에 `[ ≡ | ⊞ ]` 전환 버튼이 나타나면 바로 사용하실 수 있습니다!

## 🎮 마우스 & 키보드 조작법

- **클릭**: 우측 서지정보(메타데이터) 패널 실시간 동기화
- **더블클릭 / Enter**: Zotero 내장 PDF 리더(또는 시스템 기본 뷰어)로 논문 열기
- **방향키 (↑, ↓, ←, →)**: 마우스 없이 자유로운 카드 탐색 (포커스 이동 시 화면 자동 스크롤 추적)
- **뱃지 클릭**: `읽기전` ➔ `읽는중` ➔ `읽음` 상태 원클릭 변경
- **Cmd/Ctrl + 클릭**: 개별 논문 다중 선택
- **Shift + 클릭**: 연속 범위 다중 선택
- **Delete / Backspace**: 선택한 논문 삭제 (컬렉션에서 제외 또는 휴지통 이동)
- **검색창 입력**: 검색어 입력 시 렉 없이 실시간 필터링 (`ESC` 입력 시 즉시 전체 복원)
